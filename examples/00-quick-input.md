# Quick Input — sem formulário gigante

Você não precisa preencher uma planilha inteira para usar o sistema.

## Opção 1 — mande um print
Anexe um screenshot de Shopify, Meta Ads, Google Ads ou GA4 e diga o que quer entender.

Exemplo:

```text
/jhulie-daily

Analise este print da operação de ontem e me diga o que merece atenção hoje.
```

## Opção 2 — cole só as métricas principais

```text
Receita: $8.300
Pedidos: 118
CVR: 1,2%
AOV: $70
Meta spend: $2.100
Meta CPA: $37
Google spend: $900
Google CPA: $29
Observação: mobile caiu bastante nos últimos dias.
```

## Opção 3 — export/CSV
Se tiver um export, coloque o arquivo no projeto ou forneça o conteúdo relevante e peça ao agente para analisar.

## Regra do sistema
Comece com o que você tem.

Se faltar informação realmente importante, o agente deve pedir somente 1–3 dados adicionais que possam mudar a decisão.

O objetivo é reduzir fricção, não transformar diagnóstico em preenchimento de formulário.
