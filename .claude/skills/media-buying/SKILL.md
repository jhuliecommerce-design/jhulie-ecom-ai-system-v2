# Media Buying Framework

## Dados mínimos desejáveis
- Spend
- Revenue
- Orders/purchases
- CAC/CPA
- AOV
- Margem ou break-even
- MER/blended ROAS
- CVR da loja
- Dados específicos do canal

## Princípio
Nenhuma métrica isolada define a decisão.

## Sequência
1. Validar tracking e janela analisada.
2. Entender economia unitária.
3. Separar problema de mídia de problema de loja.
4. Cruzar eficiência com volume.
5. Identificar deterioração, estabilidade ou ganho incremental.
6. Classificar:
   - escalar;
   - manter;
   - ajustar;
   - pausar/investigar.
7. Definir um teste por hipótese.

## Guardrails
- Nunca recomende escala se break-even for desconhecido e isso impedir decisão segura.
- Nunca confunda ROAS de plataforma com lucro.
- Mudanças financeiras exigem autorização explícita quando houver ferramenta de execução.
