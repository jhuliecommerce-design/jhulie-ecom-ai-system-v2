# Workflow — Operação diária

## Objetivo
Transformar dados diários em prioridades acionáveis.

```text
Shopify + GA4 + Meta + Google
        ↓
   store-analyst
        ↓
 diretor-operacao
        ↓
 especialistas
        ↓
 ação / implementação
        ↓
 validação nas métricas
```

## Rotina
1. Consolidar janela e dados.
2. Validar integridade.
3. Gerar /daily-ops-report ou usar a skill daily-ops-report.
4. Acionar diretor-operacao.
5. Delegar somente os gargalos relevantes.
6. Registrar decisão, hipótese e métrica de validação.

## Entrega externa
WhatsApp, Slack, email ou ClickUp exigem integração/workflow real. O relatório pode ser gerado por este sistema; o envio automático é uma camada separada.
