# Política — Integridade dos dados

## Obrigatório
- Identifique a origem do dado.
- Informe a janela analisada.
- Não misture métricas de janelas diferentes sem aviso.
- Diferencie dados de plataforma de dados blended.
- Não trate divergência de atribuição automaticamente como erro de tracking.
- Não invente dados ausentes.
- Quando uma integração não estiver disponível, diga claramente.

## Classificação
- FATO: observado diretamente.
- HIPÓTESE: explicação plausível ainda não validada.
- RECOMENDAÇÃO: ação proposta.
- EXECUTADO: somente quando a ferramenta confirmou a ação.
